做 Mote 的第一天，我给自己写了两句话：**纯净如纸，强大如城**。

纸是界面，城是能力。大部分浏览器的问题不是功能不够，而是功能都挤在脸上——地址栏、书签、资讯流、广告，每一块都在争夺注意力。Mote 想做的是反过来：默认什么都没有，需要的时候才出现。

## 三层结构

我把整个产品拆成三层，每一层只负责一件事：

1. **界面层**：只保留地址栏、页面和底部工具栏，其余全部收进「更多」。
2. **能力层**：AI Agent 常驻但不显眼，用一次点击唤起，而不是用一个入口堆在首页。
3. **表达层**：动效、圆角、留白，负责让上面两层显得「轻」。

> 设计不是把所有功能做出来，而是决定哪些功能不出现在第一屏。

## 关于「不用等」的细节

浏览器是效率工具，任何超过 200ms 的等待都会被感知。我们把加载过程拆成了三段可见反馈：

- 地址栏左侧的进度条只做一件事：告诉你在动
- 页面骨架先于内容出现，减少跳变
- AI 的回答流式输出，第一个字必须在 400ms 内出现

## 一些实现上的取舍

界面用 Compose 写，圆角和阴影都收敛到一套 token 里，避免每个页面各写一套：

```kotlin
object MoteShape {
    val card = RoundedCornerShape(20.dp)
    val sheet = RoundedCornerShape(topStart = 28.dp, topEnd = 28.dp)
    val pill = RoundedCornerShape(percent = 50)
}
```

颜色同样如此。主题只有一层，深色和浅色共用同一套语义名：

```css
:root { --surface: #121316; --text: #f5f6f8; }
[data-theme="light"] { --surface: #ffffff; --text: #0c0d10; }
```
