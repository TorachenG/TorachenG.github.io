HOW TO PUBLISH

  1. 导出　点「下载 .md」，会得到一个带 front matter 的文件。
  2. 放进仓库　把文件放到 posts/ 目录下。
  3. 构建并推送　运行 python build_blog.py，再运行 python deploy_blog.py。

草稿会自动保存在这台设备的浏览器里，关掉页面也不会丢。
